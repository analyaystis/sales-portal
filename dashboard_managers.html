Как читать этот отчёт
КТУ (коэффициент трудового участия) — итоговая оценка эффективности. Выше 1.0 = работает лучше среднего, ниже 1.0 = есть зоны роста. С июля учитывается объём сделок.
KPI — качество работы с клиентами: насколько хорошо менеджер переводит клиентов в покупателей относительно коллег.
Целевые покупатели — клиенты, купившие квартиру или коммерческое помещение. Это главный результат работы менеджера.
Все показатели учитываются по дате регистрации сделки в CRM.
Конверсии C1–C5 — процент клиентов, перешедших на каждый следующий этап воронки продаж.
Диапазон: —
Рейтинг менеджеров по эффективности (КТУ) Зелёный = выше среднего · Жёлтый = ниже среднего
КТУ по команде Норма = 1.0

Как считаются показатели

КТУ = KPI × (0,4×Кнагруз + 0,3×Кактив + 0,3×Крез) / (0,5 + 0,5×Кприсут) × (1 + k×Ксумм)
KPI = 0,20×C1/С̄1 + 0,25×C2/С̄2 + 0,25×C3/С̄3 + 0,10×C4/С̄4 + 0,20×C5/С̄5
C1 Кл→Встреча C2 Кл→Бронь C3 Бронь→Покупка C4 Кл→Покупатель C5 Кл→Целевой покупатель
Кнагруз = Кл/Ср.кл Кактив = 0,5×Зв/Ср.зв + 0,5×Встр/Ср.встр Крез = 0,3×Нецел/Ср.нецел + 0,7×Цел/Ср.цел Кприсут = Отраб.дни/Раб.дни Ксумм = мин(0,5; макс(0; Σсделок/Ср.Σ−1))
(1 + k×Ксумм) — бонусный множитель за объём сделок, действует с июля 2026. k устанавливается руководством.
